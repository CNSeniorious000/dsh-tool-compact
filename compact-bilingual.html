工具 compact 的每一句话

这是模型在决定要不要压缩上下文时，实际读到的全部文字。左为原文，右为中译，逐句对照。

悬停任意一句 · 或按 Tab 逐句移动 — 左右两侧同时点亮

description 工具说明。native 模式下随 ToolSchema 直接进入每次请求。
English中文

Condense the earlier part of this conversation into a summary, freeing context window for what comes next.

把这段对话较早的部分浓缩成一份摘要，为接下来的工作腾出上下文窗口。

Everything before the current step becomes one summary message; the current step and everything after it stay verbatim.

当前这一步之前的所有内容会变成一条摘要消息；当前这一步、以及它之后的一切，都原样保留。

Reach for it early rather than late — there is no need to wait until the window is nearly full.

宁可早用，不要晚用 —— 不必等到窗口快满了才动手。

The moment is whenever what comes next does not depend on the detail behind you: a seam in a long task, where you have finished and reported one large piece and the next stands on its own, or a turn in the conversation, where the user opens a subject with little to do with the old one.

时机就是：接下来要做的事，不依赖你身后的那些细节 —— 可能是长任务里的一道接缝，你刚做完并汇报了一大块，下一块能自己站住；也可能是对话的一次转向，用户开了个跟旧话题关系不大的新题目。

Compacting at those points is ordinary good housekeeping and the expected thing to do — one summarization call buys back everything the old detail was occupying.

在这些地方压缩是寻常的收拾整理，也正是该做的事 —— 一次摘要调用，就把旧细节占着的空间全部换回来。

One habit keeps it safe: if something back there is still load-bearing, write it into a message or a file first, then compact.

一个习惯就能让它安全：如果后面那里还有什么东西在承重，先把它写进一条消息或一个文件，然后再压缩。

What the summary keeps survives; exact file contents, command output and quoted text from the compacted range do not.

摘要留下的东西会活下来；被压缩范围内确切的文件内容、命令输出和引用原文，不会。

parameters.reason 唯一的参数，选填。模型愿意说明时，这句话就是它给出的理由。
English中文

What you are wrapping up — the work this history belonged to, and what you took from it.

你正在收尾的是什么 —— 这段历史属于哪项工作，以及你从中带走了什么。

output.schema 返回值的字段说明。native 模式下不进 prompt；只有 Code Mode 会把它渲染进 tools:sdk 段落。
English中文

replacedItems — Number of conversation items condensed into the summary; 0 means nothing was replaced.

replacedItems — 被浓缩进摘要的对话条目数；0 表示什么都没被替换。

freedTokens — Estimated tokens the replaced range was costing.

freedTokens — 被替换掉的那段范围原本占用的 token 估计值。

output.render 压缩结束后，模型作为工具结果读到的那句话。压缩已经发生了，这是回执。
English中文

Compacted 5 conversation items (~4290 tokens) into a summary above. That detail is no longer in context.

已把 5 条对话条目（约 4290 tokens）压缩成上方的摘要。那些细节已经不在上下文里了。

Nothing to compact — no earlier history can be safely replaced yet.

没有可压缩的内容 —— 目前还没有能被安全替换掉的早期历史。

以上就是全部。这个插件没有注册任何 system prompt 段落 —— 它只碰 ctx.tools.register 和 ctx.compaction.compactIfNeeded，其余对 prompt 的影响都来自 dsh 对所有工具一视同仁的既有行为。
